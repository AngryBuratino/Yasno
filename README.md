# Ясно 2.2

Простой браузерный редактор для проверки русской орфографии, грамматики и пунктуации.

## Возможности

- После проверки сразу показывается готовый исправленный текст с копированием в один клик.
- Советы по деловому стилю добавляются в готовый вариант только по выбору пользователя.

- Проверка через LanguageTool и осторожные локальные правила пунктуации.
- Режим «Деловой стиль» — необязательные рекомендации для рабочих сообщений.
- Исправлено отображение устаревших результатов при вводе текста во время проверки.
- Подсветка замечаний, выбор исправлений, фильтры и отмена последнего исправления.
- Копирование результата, подсчёт слов и символов.
- Адаптивный интерфейс для телефонов.

## Запуск в Vercel

Фреймворк: **Other** (без сборки). Корень репозитория содержит `index.html` и серверную функцию `api/check.js`.

Подключите этот репозиторий к существующему проекту `yasno-2` в Vercel через **Project → Settings → Git → Connect Git Repository**, не создавая второй проект. Production Branch: `main`.

Проверка в браузере отправляет текст через маршрут `POST /api/check` во внешний LanguageTool. Если сервис не отвечает, включается **ограниченная локальная проверка** с предупреждением. Бесплатный публичный API LanguageTool имеет ограничения и не даёт гарантии доступности.

Тексты не записываются в базу данных приложения. Не вставляйте конфиденциальные рабочие сообщения, пароли и ключи: для полной проверки текст передаётся внешнему сервису.

## Разработка

- `npm test` — тесты серверной функции (без сетевых запросов).
- `npx vercel dev` — локальный запуск вместе с API (потребуется Vercel CLI).
- Открытие `index.html` как файла показывает интерфейс, но без серверного API проверка не работает.

Ограничение текста: 10 000 символов. Автоматическая проверка не гарантирует 100% точности.
