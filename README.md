# Ясно 3.0 · без ИИ

Адаптивный редактор русских сообщений: пунктуация, орфография, деловые рекомендации, сравнение «было/стало».

## Как работает проверка

- Простые, сравнительно надёжные исправления автоматически предлагаются для готового текста.
- Сложные и неоднозначные подсказки показываются отдельно и добавляются **только по желанию пользователя**.
- Используется бесплатный внешний LanguageTool и ограниченные встроенные правила. **В проекте нет обращений к OpenAI или другим генеративным моделям, ИИ-токены не расходуются.**
- Если LanguageTool временно недоступен, показывается предупреждение, и остаются только встроенные правила.
- Автоматическая проверка не гарантирует отсутствие всех ошибок. Упрощённые правила могут давать ложные срабатывания.

## Возможности

- Раздельное сравнение «Было / Стало» с подсветкой изменений.
- Исправления по одному, готовый вариант и копирование в один клик, отмена применения.
- Фильтры ошибок и краткие объяснения правил.
- Режим деловой переписки: четыре шаблона, осторожные замены для вежливого и краткого тона (не генеративный рерайт).
- Личный словарь названий и слов, локально на устройстве.
- История сохранённых сообщений **только по нажатию** «Сохранить».
- Необязательное автосохранение черновика (по умолчанию выключено).
- Тёмная тема, адаптивный мобильный интерфейс, PWA-установка.
- Инструменты оценки длины сообщения и примерного времени чтения.

## Приватность

Текст не сохраняется на сервере приложения. При проверке он отправляется внешнему LanguageTool — **не отправляйте пароли, закрытую рабочую переписку или другую конфиденциальную информацию**.

Словарь и история хранятся в `localStorage` браузера, черновик — тоже только при явном включении соответствующей настройки. Удаление данных браузера удалит эти материалы. Не храните чувствительные сообщения в истории общего устройства. Сервис-воркер кеширует только файлы приложения, **не текст и не API-ответы**.

## Разработка

- `index.html`, `styles.css`, `app.js` — интерфейс.
- `app-core.js` — локальные функции (сравнение, шаблоны, словарь).
- `api/check.js` — проверка через LanguageTool и правила.
- `advanced-punctuation.js` и `corrections.js` — локальная пунктуация и применение исправлений.
- `sw.js`, `manifest.webmanifest`, `icon.svg` — PWA.
- `npm test` — автоматические проверки Node.js; `npx vercel dev` — запуск локально.

Рабочая ссылка: https://yasno-2.vercel.app/ . Обновления публикуются из ветки `main` GitHub-репозитория `AngryBuratino/Yasno`.

## Дальнейшие улучшения

До настоящей универсальной проверки сложного русского синтаксиса система не дотягивает: без полноценных языковых моделей расширение правил требует тщательных тестов на ложные срабатывания. Пополняйте тесты реальными **обезличенными** примерами.
