# Ясно 2.4 — сложная пунктуация

Браузерный редактор русского текста с проверкой орфографии, пунктуации и дополнительными подсказками.

## Проверка текста

- LanguageTool проверяет орфографию и грамматику, резервные локальные правила работают при его недоступности.
- Переключатель **«Сложные запятые»** включён по умолчанию. Находит возможные границы придаточных частей (что, когда, если, который), отдельные вводные конструкции и типичные причастные обороты.
- **Два уровня уверенности:** запятые в небольшом наборе достаточно определённых конструкций (например, «я думаю, что…», «встретиться, когда…») сразу попадают в готовый текст. Остальные подсказки помечаются «На проверку», по умолчанию не применяются и добавляются только после явного выбора пользователя. Это эвристики, а не полный синтаксический анализ.
- Готовый исправленный текст копируется одним нажатием. Рекомендации по деловому стилю можно применять отдельно.
- Не сохраняем тексты на сервере приложения.

## Необязательный ИИ-анализ

В интерфейсе есть опция «ИИ-анализ *», **по умолчанию выключена**. Она доступна только после настройки API-ключа. Использует Responses API OpenAI, модель `gpt-4.1-mini` (можно изменить через `OPENAI_PUNCTUATION_MODEL`).

Чтобы включить: в Vercel открой **Project → Settings → Environment Variables**, добавь **Secret** `OPENAI_API_KEY` и заново разверни сайт. **Никогда не отправляй API-ключ в чат и не добавляй его в GitHub.** OpenAI API может взимать плату за запросы; предварительно настрой лимиты расходов в платформе OpenAI.

ИИ проверяет тексты до **1800 символов** и может предлагать **только изменения запятых**. Любое изменение слов, пробелов, переносов или других знаков сервер отклоняет. Все ИИ-подсказки требуют ручного подтверждения. Не включайте платную ИИ-проверку на публичном сайте без защиты от злоупотреблений. Если ключа нет, будет показано понятное предупреждение, а обычная проверка продолжит работать.

**Приватность:** при обычной проверке текст отправляется в LanguageTool, а при явно включённом ИИ-анализе и настроенном ключе — дополнительно в OpenAI API. В запросах к Responses API используется `store:false`. Не загружай секретную рабочую переписку.

## Запуск и тестирование

- Веб-интерфейс: `index.html`, `corrections.js`.
- API: `api/check.js`.
- Эвристики: `advanced-punctuation.js`; ИИ-проверка: `ai-punctuation.js`.
- `npm test` запускает тесты Node.js.
- `npx vercel dev` поднимает приложение локально вместе с API.

GitHub: `AngryBuratino/Yasno`, ветка `main`; существующий проект Vercel: `yasno-2`.

Автоматическая проверка не гарантирует отсутствия всех ошибок. Публичный LanguageTool ограничивает количество запросов и не гарантирует доступность.
